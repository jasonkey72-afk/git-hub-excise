Dev Tools Autodown - 설치 안내

1. Python 3.x 설치 (이미 있으면 생략)
2. 아래 명령으로 필요한 패키지 설치
   pip install -r requirements.txt
3. Microsoft Edge 브라우저가 설치되어 있어야 함 (Windows 기본 내장)
4. 실행
   python installFileAutoDown.py
5. "다운로드 시작" 버튼 클릭 -> VS Code / Python / PowerShell 7 설치파일을
   실제 브라우저 자동화(Selenium)로 각 사이트에서 클릭해 받아온다.
6. 다운로드 완료 후 "설치 시작" 버튼으로 받은 설치파일 실행.
