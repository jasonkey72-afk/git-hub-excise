Prompt Pattern

초보자용 Prompt 공식

1. 업무 설명

“나는 매일 이 사이트에 접속해서 조건을 넣고 결과를 엑셀로 저장한다.”

2. 입력/출력 정의

“입력은 날짜와 품번이고, 출력은 다운로드된 Excel 파일이다.”

3. 제약조건

“Edge 브라우저를 사용하고, 회사 보안상 계정 정보는 코드에 넣지 않는다.”

4. 실행 요청

“초보자도 실행할 수 있게 단계별로 만들어줘.”
